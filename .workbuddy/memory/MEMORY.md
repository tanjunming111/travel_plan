## 核心业务规则（v2.1 生效）
- **计划**：默认名「{开始} 至 {结束} 旅行」/「{地点}之旅」；改期事项整体平移（缩短末尾删除需确认）；列表按创建时间倒序；允许过去日期；删除二次确认；「一键清空」需随机 6 位验证码（首位非 0）
- **事项**：HH:mm 分钟级、不跨天；重叠判定 `新开始<旧结束 && 新结束>旧开始`（首尾相接允许）；按开始时间升序；时间输入 AA:BB 双数字框（分钟留空默认 00）；介绍/备注用勾选开关录入；每天红色「一键删除」（清空当天事项+花销）
- **花销（一对多）**：存 trip.expenses，项 `{id, day, title, amount(分,整数), remark, itemId?, time}`；一个事项可关联多个花销（expense.itemId 指向事项，事项侧动态 filter，无 expenseId 字段）；**标题可留空=空标题**（事项弹窗内每行金额+标题选填+删除，「＋ 添加花销」加行，删除直接删）；金额非负、最多两位小数、上限 999999.99 元，分整数求和防浮点；汇总=每日「今日花销」（>0 显示）/事项卡片总和/计划头部「总花销（查看详情）」；time=事项开始时间（事项来源）/添加时刻（独立项）/导入时刻；改期时带 itemId 花销随事项平移、独立项留原日期、压缩天删除
- **spend 页**（?id=&preview=1 预览只读）：总花销 → 日期下拉 → 每日花销 → 花销项按 time 排序增删改；**显示规则：事项关联花销标题非空→「事项标题 - 花销标题」、空→「事项标题」；独立项显示自身标题并紧贴 * 标记**；「导出花销」按钮在总花销下方；删除绑定事项花销二次确认并提示「对应事项花销一并删除」
- **导入导出（文字）**：标记格式【旅游计划】【起止日期】【注意事项】【第N天 MM月DD日】（无空行）；**花销行 `花销：金额元（标题）`（无标题不加括号；多条 `A元（标题1）+B元 = 总和`；备注不导出；独立花销不导出）**；导入还原为关联事项花销（标题=括号内容或空、备注空、time=导入时刻，解析前切除「= 总和」）；导入始终新建计划、重名加后缀；Word 导出不含花销

## 踩坑速记
- 多顶层节点 el() 须返回 DocumentFragment；OOXML 表格 pct 值 ×50（100%=5000）；jsdom 中 JSZip.generateAsync 挂起（环境限制）；异步确认弹窗断言需 setTimeout；jsdom 的 textarea 内容在 value、input.value 赋值不触发 input 事件（测试需手动 dispatchEvent）；中文路径删除用 PowerShell；部署接口偶发 400 重试即可
- 花销：导入解析**先切除「= 总和」**（否则无括号分支误解析）；金额用分整数运算防浮点；`Store.newExpense(day,title,cents,itemId,remark,time)` 参数别漏传；事项弹窗花销行金额在左标题在右
